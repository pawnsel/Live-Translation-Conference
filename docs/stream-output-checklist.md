# Checklist ทดสอบหน้าต่าง Output บนเครื่องจริง

ทำบน **macOS หนึ่งเครื่อง และ Windows หนึ่งเครื่อง** ต่อจอ projector (หรือจอที่สอง)
แบบ **extend** ใช้เวลาประมาณ 1 ชั่วโมง

Setup ที่ทดสอบ: จอโน้ตบุ๊คมี console + หน้าต่าง PowerPoint, จอที่สองมีหน้าต่าง
Output เต็มจอ

## เตรียม
- [ ] จอที่สองตั้งเป็น **extend** ไม่ใช่ mirror
- [ ] macOS: System Settings → Privacy & Security → Screen Recording เปิดให้ Chrome/Edge แล้ว
- [ ] เปิด PowerPoint **แบบหน้าต่าง** (ไม่ใช่ slideshow เต็มจอ) บนจอโน้ตบุ๊ค

## หน้าต่าง Output
- [ ] แท็บสตรีม → เลือกหน้าต่างสไลด์ → แท็บ **หน้าต่าง** → เลือกหน้าต่าง PowerPoint — ภาพตัวอย่างขยับ
- [ ] เปิดหน้าต่าง Output — ได้ popup เห็นสไลด์
- [ ] ลากหน้าต่าง Output ไปจอที่สอง → กดปุ่มเต็มจอมุมขวาบน — เต็มจอไร้ขอบ ไม่มีแถบ address bar
- [ ] เมาส์นิ่ง 2 วินาที — ปุ่มเต็มจอและเมาส์เคอร์เซอร์หายจากจอที่สอง
- [ ] ขยับเมาส์บนจอที่สอง — ปุ่มกลับมา
- [ ] กด Esc — ออกจากเต็มจอ ปุ่มกลับมาเป็น "เต็มจอ" อีกครั้ง (ไม่ค้างเป็น "ออกจากเต็มจอ")
- [ ] แถบ "Chrome กำลังแชร์หน้าจอ" ขึ้นจอไหน: ______ (ถ้าขึ้นบนจอที่สองกด "ซ่อน")

## ระหว่างพูด
- [ ] เริ่ม session พูด — คำแปลบนจอที่สองตรงกับกล่องใน console
- [ ] ใช้รีโมต/คีย์บอร์ดเลื่อนสไลด์ — สไลด์บนจอที่สองเปลี่ยนตาม คำแปลยังขึ้นต่อเนื่อง
- [ ] คลิกปรับค่าใน console แล้วกดรีโมต — สไลด์ไม่เลื่อน (ปกติ) คลิกที่ PowerPoint หนึ่งครั้งแล้วเลื่อนได้
- [ ] เปิดคลิป YouTube ในหน้าต่างที่แชร์ — จอที่สองเห็นคลิป
- [ ] minimise console — คำแปลบนจอที่สองยังขยับ
- [ ] เปลี่ยนขนาดตัวอักษร / ธีม (รวมโปร่งแสง) — จอที่สองเปลี่ยนตามทันที
- [ ] ลากแถบคำแปล → ล็อก → ลากไม่ได้ → ปิดเปิดหน้าต่าง Output แล้วตำแหน่งยังอยู่
- [ ] สลับเป็น **แบ่งพื้นที่** แล้วปรับ **ขนาดสไลด์** หลายระดับ (รวมค่าสูงสุด) — บนจอที่สอง
      คำแปลไม่บังสไลด์เลย แม้เปิด "แสดงประโยคต้นฉบับ" ที่ทำให้แถบคำแปลสูงขึ้น
- [ ] ติ๊ก "ซ่อนคำแปลชั่วคราว" — คำแปลหายจากจอที่สอง ไม่เหลือเส้นขอบใดๆ

## กรณีผิดปกติ
- [ ] กด "หยุดแชร์" ของ Chrome — จอที่สองเป็นพื้นดำ + คำแปล, แท็บสตรีมบอกแชร์สไลด์หยุด, แชร์ใหม่ได้
- [ ] ถอดสาย projector ตอนเต็มจอ — หน้าต่าง Output กลับมาจอโน้ตบุ๊ค เสียบใหม่แล้วลากกลับไปเต็มจอได้
- [ ] กด refresh console — เบราว์เซอร์ถามยืนยัน
- [ ] เผลอเลือก "ทั้งหน้าจอ" ของจอที่สอง — เห็นภาพซ้อนไม่รู้จบ แก้ได้ด้วยการแชร์ใหม่เป็นหน้าต่าง

## ทนทาน
- [ ] เปิดทิ้งไว้ 1 ชั่วโมงระหว่างพูดเป็นระยะ — ภาพบนจอที่สองไม่กระตุก ไม่ค้าง คำแปลไม่ล่าช้าลง
